# FullMicrochangeCS

Tool for very fast **changing default microphone and speakers** through system tray

Тулза для очень быстрого **изменения микрофона и динамиков** через системный трей

---

## English

In this version you just need to upload three files

* AudioSwitcher.AudioApi.dll
* AudioSwitcher.AudioApi.CoreAudio.dll
* FullMicrochange.exe

Into the necessary directory and just run! No unnecessary installations! Except if you need components to work, for example, .Net Framework.

## Русский

В данной версии вам необходимо просто выгрузить три файла

* AudioSwitcher.AudioApi.dll
* AudioSwitcher.AudioApi.CoreAudio.dll
* FullMicrochange.exe

В необходимую директорию и просто запустить! Никаких лишних установок! Ну разве что если компоненты для работы, например, .Net Framework.
